# 🤖 AI Code Explainer

An AI-powered code explainer designed to help learners understand and debug code across multiple programming languages.

## ✨ Features

- 🧠 **Explain Code** — Get a simple explanation of what your code does.
- 🐛 **Find Bugs** — Detect bugs, edge cases, and potential security issues.
- 📊 **Complexity Analysis** — Get approximate time and space complexity.
- 💻 **Multiple Languages** — Supports Python, JavaScript, Java, C, C++, and C#.
- 🎨 **Developer-Friendly UI** — Clean dark-themed interface.
- ⚡ **FastAPI Backend** — Lightweight Python API.
- 🤖 **Gemini AI** — AI-powered code analysis.
